# آگارتا پورتال جنسیس | APG Presence

این مخزن عمومی، کد آزمایشی برای بررسی یک پیام امضاشدهٔ اتریوم به روش EIP-191 و مقایسهٔ امضاکننده با نشانی مورد انتظار ROOT را ارائه می‌کند. نشانی مورد انتظار در بررسی‌کنندهٔ خط فرمان ثابت است و به محتوای قابل‌تغییر مانیفست واگذار نمی‌شود.

**وضعیت فعلی:** جایگاه اثبات Presence v1 بدون امضاست. موفقیت آزمون‌ها و GitHub Actions به معنی اثبات امضای تازهٔ ROOT نیست.

## اجرای بررسی

با Node.js نسخهٔ ۲۲:

```sh
npm ci --ignore-scripts
npm test
npm run verify:ci
npm run verify
```

تا زمانی که اثبات امضاشدهٔ معتبر وجود نداشته باشد، دستور `verify:ci` وضعیت انتظار را گزارش می‌کند و دستور سخت‌گیرانهٔ `verify` ناموفق پایان می‌یابد. راهنمای متن دقیق پیام و امضا در [presence/README.md](presence/README.md) آمده است.

## مرز نتیجه

این کد امضای ECDSA و محتوای پیام را بررسی می‌کند؛ هویت شخص، انتقال دارایی، درآمد، مالکیت NFT یا تراکنش روی زنجیره را ثابت نمی‌کند. بررسی کیف پول قراردادی به روش ERC-1271 و ثبت nonceهای مصرف‌شده در این نسخه پیاده‌سازی نشده است. تاریخ‌های داخل پیام ادعای امضاشده‌اند، نه گواه مستقل زمان امضا.

هیچ‌گاه عبارت بازیابی یا کلید خصوصی را در مخزن یا وب‌سایت وارد نکنید. امضای یک پیام Presence با تأیید انتقال، مجوز خرج یا واگذاری متفاوت است؛ متن دقیق را پیش از هر امضا بخوانید.

برای جزئیات فنی و پیوندهای عمومی، [راهنمای انگلیسی](README.md) و [گزارش فنی](PUBLIC_TECHNICAL_BRIEF.md) را ببینید.
