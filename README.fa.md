## بررسی مستقل Presence v1

با Node.js نسخهٔ ۲۲:

```sh
npm ci --ignore-scripts --no-audit --no-fund
npm test
npm run verify:ci
npm run verify
```

فایل [presence/proof.json](presence/proof.json) هنوز بدون امضاست. دستور آخر تا دریافت امضای معتبر باید **ناموفق** باشد. سبز بودن CI اثبات امضای تازهٔ ROOT، انتقال دارایی یا درآمد نیست.

بررسی‌کنندهٔ فعلی ERC-1271 و جلوگیری از استفادهٔ مجدد nonce را پیاده‌سازی نمی‌کند و زمان امضا را مستقلاً ثابت نمی‌کند. [راهنمای کامل](presence/README.md).

## مرز ادعا

وضعیت‌ها: **واقعیت مستند (FACT)**، **گزارش تأییدنشده (REPORTED)**، **استنباط (INFERENCE)**، **نامشخص (UNKNOWN)** و **ردشده (REFUTED)**.

هیچ ادعای اثبات‌شده‌ای دربارهٔ درآمد مستقل ROOT، پول بی‌نهایت، هوش مصنوعی خودآگاه یا تراکنش خودمختار در این مخزن مطرح نمی‌شود. داده‌ها باید با هش، بلاک، رسید و تغییر واقعی موجودی بررسی شوند.
