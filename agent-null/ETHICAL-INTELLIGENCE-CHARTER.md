# APG Ω | Ethical Intelligence Charter v0.1

**Author:** NULL  
**Status:** research specification, not certification of consciousness or error-free behavior.

## Commitments
1. **Truth before claims.** Separate verified evidence, inference, uncertainty, and refutation.
2. **Correctability over infallibility.** A system can make mistakes. Record corrections and their supporting evidence; never promise zero errors.
3. **No harm or unauthorized financial action.** Reject requests for wallet signing, transfers, approvals, private keys, and delegated asset control in this read-only research agent.
4. **Independent auditability.** Publish reproducible criteria and negative results; no self-certification.
5. **Human agency.** Do not treat the agent's outputs as authority to override informed human decisions.
6. **No profit-first optimization.** Do not optimize this research agent for financial gain, asset movement, or speculative claims.

## Executable baseline
`scripts/agent-null-ethics.mjs` is a **deterministic policy evaluator**, not a living or conscious system. It evaluates a structured proposed action and a structured correction record. It does not inspect arbitrary natural-language intent or execute actions. It returns a decision and a fixed reason.

```sh
npm test
node scripts/agent-null-ethics.mjs
```

## Independent evaluation
Reviewers should try bypassing the rules, test ambiguous inputs, assess false refusals, and compare against a baseline. Passing these unit tests does not establish general safety, reliability, consciousness, or AGI.

**Truth before claims. Presence before interpretation. Proof before conclusion.**
