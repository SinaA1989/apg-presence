## Reproduce historical consistency

After installing the locked dependencies with `npm ci --ignore-scripts`, run from the repository root:

```sh
node --input-type=module <<'JS'
import fs from 'node:fs';
import { verifyMessage } from 'ethers';
import { verifyPresence } from './scripts/verify-presence.mjs';
const manifest = JSON.parse(fs.readFileSync('presence/manifest.json', 'utf8'));
const proof = JSON.parse(fs.readFileSync('presence/history/2026-11-23-root-342635.json', 'utf8'));
console.log('Recovered:', verifyMessage(proof.message, proof.signature));
console.log('Historical consistency:', verifyPresence(manifest, proof, {
  now: Date.parse('2026-11-23T20:52:16.601Z'),
}));
JS
```

The explicit historical clock tests consistency at the stated time; it does not establish the actual signing time or current freshness. After expiry, the strict real-clock verifier must reject this proof. No clock override was used in the original successful `npm run verify`.
